# @framekore/debugger2d

Este pacote foi concebido para expor internamente variáveis visuais essenciais da engine para facilitar a correção de erros de arquitetura.

## Estado Atual
🚧 **Work in Progress (WIP)**

No momento o plugin `debugger2d` está reservado e inativo. 
Futuras iterações incluirão:
- Renderização forçada dos retângulos AABB limitadores gerados por `BoxCollide2D` de forma sobreposta (Overlays).
- Exibição de estatísticas do Ticker como TPS (Ticks per Second) e FPS.
- Wireframes dos nodes da árvore de cena.
